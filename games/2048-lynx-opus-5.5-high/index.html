Hex 2048

2048 on a 19-cell hexagonal board, written in C for the Atari Lynx and running here in a JavaScript build of the Handy emulator.

How to play

Slide all tiles in one of six directions. Equal tiles that collide merge into their sum. Reach 2048, then keep going until the board locks up.

Keyboard shortcuts
QWEASD
NW, N, NE / SW, S, SE: one key per hex direction
Lynx D-pad↑ ↓ slide N / S; diagonals ↑+← etc. slide NW / NE / SW / SE
← / → alone slide NW / NE; hold X (Lynx B) for SW / SE
Lynx AZ start / continue / retry
Option 1N new game
