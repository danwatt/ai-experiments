How it fits

The board is a 7×7 grid of axial hex coordinates with a wall ring, so the six slide directions are just index offsets: ±1, ±6, ±7.

Tiles are visited front-first and slide until they hit a wall, a different tile or a merge. Merged cells get bit 7 set so they can't merge twice; the redraw clears it.

Each hex is three text rows: ▄▄▄▄▄, a 7-cell face with the number, ▀▀▀▀▀. Blink is turned off so the faces can use bright backgrounds.
