HEXAHEDRON 64

The Descent-style 6DOF mine run, rebuilt as a bare-metal Nintendo 64 ROM and running here in mupen64plus-next (EmulatorJS). Three missions, three robot types, lasers, spreadfire and homing missiles.

Click the play button first (browsers only allow sound after a click). On the title screen, ↑/↓ pick a mission. A USB or Bluetooth gamepad also works; the emulator's menu (bottom bar) lets you remap keys.

Missions

  • Prospect Station: the red key sits over the lava in the cavern east of the Upper Hall. Break into the reactor, destroy it, and get back to the Hangar before the mine blows.
  • Hexahedron Deep Works: blue key in a crystal grotto opens the deep works; the red key is somewhere hot beyond it. Reactor, then escape.
  • Overseer Citadel: blue, yellow and red keys through three locked sectors to the Overseer's core.

The maps are exported from the browser version's level generator, so the cube layout, doors and baked lighting match Hexahedron.

How it's made

C with no SDK at run time: the game drives the VR4300, RDP, VI, PIF and AI registers itself. The CPU transforms, lights, clips and sets up every triangle and writes raw RDP command lists; the RSP is never used. A small custom boot stub replaces libdragon's IPL3 (which these emulator cores can't boot). Built in Docker with libdragon's MIPS toolchain; see README and hexahedron64.z64.
