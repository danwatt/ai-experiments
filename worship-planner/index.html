Shared core

  • One data model for services, items, songs and slide sets, synced across devices.
  • Local search index (for example SQLite FTS5) over title, first line, tune, meter, scripture and topic, so search works offline in the sanctuary.
  • Scripture aliases resolve both ways: Ps 118 finds Psalm 118.

Desktop only

  • Four-part shape-note slides, one per verse, at the songbook’s pitch.
  • Drag and drop between library and order, keyboard-first search, presenter view.
  • Export to .pptx for the projection computer. The in-window menu moves to the system menu bar on macOS.

Mobile scope

  • Song leader view: every song with its number, starting pitch and verses. No sheet-music files on the phone.
  • Pick songs and verses, see who is serving, confirm assignments. Changes sync back to the desktop.
  • Try it: add a song on a phone, then switch to Desktop.
