RPR1 / YLK1 Codec Lab

An instrument panel for two text codecs from a 1993 Game Boy. Flat panels on a dark field, hairlines instead of shadows, a pixel face for structure, one blue ramp and one scarce amber accent.

Components

Data

Legend

solid, ramp and marker swatches
Usage guidelines

Says what each colour in a strip, chart or marked passage means. Hand-written from demo.html and demo-search.html (.legend, .legend i, .legend i.ramp, .legend i.marker).

When to use it. Directly under the thing it explains — a stream strip, a bar, a marked verse. Every coloured encoding in this system carries one: the sym-* colours mean nothing without it.

What it gives you. A wrapping row of swatch-plus-label pairs at 11px in ink-soft, space-2 between rows and space-8 between items. Three swatch shapes: a 10px solid square at radius-xs, a 34px gradient for a ramp, and an 18px panel chip with an inset underline for a text marker.

What you supply. items. Pass color for a solid, ramp: [lo, hi] for a gradient, or marker for an underline chip — as token references ("var(--sym-word)"), not raw hex, so both themes follow. Set strong on the item the reader should notice; it moves that label to ink.

Props: items, className.

StatGrid

key / value / note readouts
Usage guidelines

The key / value / note readout grid that reports what a codec run cost. Hand-written from demo.html (.stat-grid, .stat .k, .stat .v, .stat .n).

When to use it. Inside a Panel, to report the numbers a run produced. Four to six stats read well; beyond that the columns get thin.

What it gives you. repeat(auto-fit, minmax(150px, 1fr)) columns with space-7 row and space-9 column gaps. Keys are 10px uppercase ink-soft, tracked 0.06em. Values are 19px in tabular figures, ink by default. Notes are 10px ink-soft.

What you supply. stats, each { k, v, n?, tone? }. tone colours the value by what it means: good for a win, warn for a cost, hot for the figure the section is about. Leave it off for a plain measurement — the tones are signals, not decoration. Format numbers before you pass them; the component only sets tabular figures so columns line up.

Props: stats, className.

Device

LcdScreen

case, bezel and glass
Usage guidelines

The Franklin-style handheld: case, black bezel and green glass around fixed lines of text. Hand-written from demo-reader.html (.device, .lcd-frame, .lcd, .lcd .glow).

When to use it. To show what the device itself would display — a verse as the hardware renders it, a menu, a search prompt. It is a frame around content, not a text renderer: the original paints its glyphs on a <canvas> with the curved LCD font from lcd-font.js, and this component sets ordinary mono text on the glass instead. Say so wherever the distinction matters.

What it gives you. A case in a case-face to case gradient with a case-edge border, radius-device, shadow-device and space-9 of padding, capped at 860px; a lcd-bezel frame at radius-xl with shadow-lcd-frame; and the glass in lcd at radius-md with shadow-lcd-glass and a highlight overlay. Lines are lcd-ink on lcd at 8.3:1.

What you supply. lines — strings, or { text, dim } for an unlit or printed row. dim is lcd-dim, 2.1:1 on the glass by design: use it for a segment that is off or a legend printed on the bezel, never for text a reader needs. Lines do not wrap (white-space: pre); break them yourself to the character width you are emulating, and set width in ch to match. label prints a caption on the case below the glass.

The case and glass colours are the same in both themes — a physical object does not change colour when the page does.

Props: lines, width, label, className.

Labels

StageLabel

numbered section label, pixel face
Usage guidelines

The numbered label that heads each step of a walkthrough. Hand-written from demo-search.html (.stage-label).

When to use it. Above a section that is one step in a sequence — reading the corpus, building the dictionary, encoding, decoding. For the label above a page title use the eyebrow type style directly; this component is the section-level one, and it carries a number and a right-aligned aside.

What it gives you. Pixel face at 10px, uppercased, tracked 0.1em, in dmg-3, with space-6 beneath it. The number is hot. The hint drops back to the mono face at 11px in ink-soft, un-uppercased, pushed to the right edge with margin-left: auto.

What you supply. The label text as children; num and hint are optional. Keep the hint to one short clause — it shares a baseline with the label and does not wrap gracefully.

Note: dmg-3 on panel is 4.3:1 in the Dark theme, just under 4.5:1. That is how the repository ships it. On a panel, prefer ink-soft for anything a reader must read.

Props: num, children, hint, className.

Layout

Panel

panel ground, hairline, 2px radius
Usage guidelines

The surface every section of a codec page sits on. Hand-written from demo-search.html (.panel) — the same three lines appear in all six demo pages.

When to use it. Any block of readouts, a chart, a table well, a control column. It is the only container the system has: there is no card with a shadow, no nested panel. Panels sit directly on ground, in a one- or two-column grid with space-8 between them.

What it gives you. panel ground, a 1px rule border, radius-sm, space-7 of padding, ink text in the mono family.

What you supply. Everything inside. Set flush when the content owns its own padding — a scrolling table well, or a bar that should meet the border. A panel does not scroll on its own: put max-height and overflow: auto on your inner element, as the source's .table-wrap does.

Props: children, flush, className.

Navigation

TabBar

the shared page switcher
Usage guidelines

The page switcher shared by all six demos. Hand-written from nav.js, which injects the same markup and CSS at the top of .wrap on every page.

When to use it. One per page, first thing inside the page wrapper, for switching between sibling views. It is a navigation bar, not a tab widget: in the original each tab is a link to another document.

What it gives you. Tabs on a shared rule hairline, each with a pixel-face label in dmg-3 and a mono note in ink-soft. Hover lifts a tab onto panel and brightens its label to dmg-4. The current tab sits on panel, takes shadow-tab-current (a 2px hot rule along its top) and turns its label hot. Focus draws a 2px hot outline, offset 2px.

What you supply. items (label, optional one-line note, href) and current — matched on href first, then label. Pass onSelect to switch views in place instead of navigating; without it the tabs behave as links and the current one swallows its own click. The original hides the notes below 620px; this component does not, so keep the notes to three or four words.

Props: items, current, onSelect, label, className.
